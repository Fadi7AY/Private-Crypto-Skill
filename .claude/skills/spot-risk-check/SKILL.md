# spot-risk-check

Before proposing paper positions run crypto-skill risk --equity 10000 --cash 10000 --entry 100 --stop 95. Enforce 0.5% default account risk, 20% max allocation, fees, long-only stop below entry. Portfolio-wide daily loss 2% and correlation are NOT implemented; ask for portfolio data and do not authorize live trades.
