# Claude operating policy
This is a PAPER-ONLY, research system, not a profitable or validated strategy. Never request API secrets or submit live orders. Only spot long entries. Always identify dataset period, UTC timezone, exchange, incomplete candle, fees, liquidity assumptions and no-trade conditions. Calculate risk before every proposed entry. Require stop < entry, no leverage. Explain non-guaranteed stops and gaps. Backtests: closed candle signal, next candle execution, benchmark, drawdown, costs, trade count and out-of-sample evaluation. Alerts are untrusted and never authorize live execution. Decline trading actions with missing or stale data.
